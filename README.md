# 拾页 · EPUB 阅读器

拾页是一款 Windows 本地 EPUB 阅读器，支持摘录笔记、本地听读与可选的 DeepSeek AI 伴读。

ReadingText is a local EPUB reader for Windows, featuring notes, offline text-to-speech, and optional DeepSeek AI discussions.

Windows 下载：[Releases](https://github.com/zzzEasono11y/readingtext/releases)。源码采用 MIT 许可证；字体和语音组件遵循各自随附的许可证。

一个面向 Windows 的本地电子书阅读器 MVP。导入一本书，调整到舒服的排版，关闭后还能接着读。

## 直接使用

构建后的 `dist/ReadingText-0.16.1-Windows.exe` 是 Windows x64 免安装程序，双击即可运行。也可以使用 `dist/win-unpacked/拾页.exe`，但必须保留同目录的其他文件。升级后会继续使用原有书架、阅读进度和书签。

1. 点击「导入 EPUB」，选择本地电子书；没有现成书籍时可以先导入原创示例书。
2. 点击书架上的书籍封面进入阅读。
3. 滚动阅读正文，使用目录或底部按钮切换章节。
4. 「Aa 排版」可以选择字体，调整字号、行距、段距和阅读宽度。
5. 阅读位置自动保存，关闭后在书架点击「继续阅读」即可恢复。

键盘：在正文中使用鼠标滚轮、方向键上下或 Page Up / Page Down 滚动；左右方向键切换章节；Ctrl+B 保存当前位置为书签；Ctrl+F 打开书内搜索；Ctrl+Shift+Q 切换安静阅读；F11 切换全屏。安静阅读中，Esc 优先关闭当前对话框，再退出安静阅读；普通阅读中，Esc 关闭工具面板或退出全屏。

## 0.16.1：修复 Windows 文件拖入

修复从资源管理器拖入 EPUB 后提示框出现、松开却没有反应的问题：通过 Electron 的 `webUtils.getPathForFile` 获取真实磁盘路径，替代已移除的 `File.path`。拖入结束会收起提示；无法读取路径时提示使用「导入 EPUB」，损坏的书会显示具体错误，仍可重新尝试。支持中文路径、多个文件、当前分类导入与重复书籍检查。

新增真实磁盘文件拖放回归，并在免安装包检查中覆盖拖入后打开阅读。开发验证使用独立书架；可用 `READINGTEXT_SMOKE_EPUB` 指定要验证的本地 EPUB。

## 0.15：安静阅读

点击阅读工具栏的叶片「安静」，或在正文按 Ctrl+Shift+Q，收起目录、顶部工具、底部进度和听读悬浮按钮，只保留原文。鼠标移到窗口顶部或底部的 12 像素边缘即可临时显示操作；离开操作区后自动收起。临时工具浮在正文上方，不改变正文尺寸和阅读位置。

安静阅读可以配合 F11 全屏使用。按 Esc 先退出安静阅读，再按一次才退出全屏；打开的原生对话框优先处理 Esc。选中文字仍可主动标注或写笔记，正在播放的听读继续；打开目录、搜索、排版、AI 讨论或听读面板时回到普通阅读界面。进入时收起已打开的工具面板，退出后恢复原先的目录显示状态。

切换时保留当前段落，翻章后继续保持安静阅读，阅读进度照常保存。回到书架或重新启动后恢复普通阅读，方便发现所有工具；本轮不增加持久化设置或修改书架数据格式。

## 0.14：淡蓝玻璃界面

- **书架**：统一为淡蓝雾面背景、悬浮侧栏和轻量卡片；继续阅读保留真实封面，气泡仅作静态背景装饰。封面完整显示，书名、作者与阅读进度的层次更清楚。
- **阅读工具**：统一线条图标和胶囊分组，选中状态随面板同步；小窗口收起书签、摘录、搜索及全屏的文字，保留图标、悬停提示和无障碍名称。全屏切换后保留图标并更新提示。
- **面板与反馈**：排版、摘录、听读、AI 讨论及弹窗统一淡蓝玻璃材质。轻微按压反馈只作用于指针操作，键盘操作即时响应；减少动态效果时取消缩放反馈。为小窗口的发送按钮预留空间，避开听读按钮。

正文沿用已保存的字体、背景和排版设置。本轮不改动书架数据格式，也不新增依赖；新增窗口布局、键盘及减少动态效果验证，并回归现有阅读、分类拖动、听读和 AI 流程。

## 0.13：原文依据、截图提问与伴读面板整理

- **可核对的原文依据**：模型可在解释后引用所选原文中的短句；程序逐字匹配后生成「原文 1」按钮。点击会回到本书对应位置，短暂显示蓝色定位底色，并可使用「返回原位置」。回答下方的「原文依据」默认收起，展开可对照章节与引用全文。复制回答会附上这些引文。无法匹配的引用标为「引文未匹配」，不会伪造可跳转出处。
- **核对范围**：只核对当前文字会话所选原文，最多 8 条、每条 600 字符，不自动读取后文或整本书。模型未给出可匹配引用时，界面如实说明。逐字匹配仅确认引用文字存在，不保证文学解释或推论正确；外部作者生平、历史背景、书目及网页说法未联网核验。本版不提供外部资料自动检索。
- **截图提问**：打开阅读页「AI 讨论」，点击输入框下方的相机「截图」，拖选当前阅读区域。先预览，再点击「加入问题」，最后发送才上传给 DeepSeek。可用 Esc 取消框选，关闭预览或移除待发送图片；不会截取桌面、其他程序或工具栏。不必先摘录文字，没有会话时会建立独立截图会话，不自动标注或加入摘录。
- **图片与记忆**：每轮最多一张 JPEG，最长边 1600 像素、编码约 500 KB 以内；截图随该轮讨论保存、重启恢复及备份。可点击缩略图或用键盘放大查看。追问会重新携带本会话中的图片，重新生成保留该轮图片，因此图片和长历史会增加 API 用量。模糊文字、图表刻度、数字和公式仍需人工核对。截图会话不提供将占位标题加入文字摘录或生成文字笔记的按钮；可复制回答。
- **模型与保存**：图像理解使用现有 DeepSeek 账号的 `deepseek-flash`；当前图片会话选择不支持的型号时，会在请求发出前提示切换，不自动替换你的模型设置。写入失败只需重试本地保存，不重新调用模型。截图以内嵌数据保存在 `library.json`，全库图片编码总量最多 32 MiB，备份元数据上限提高到 64 MiB。较大的图片库可能增加保存耗时，建议定期备份和整理；不建议再用旧版程序编辑含引用或截图的书架。
- **界面**：沿用淡蓝玻璃背景，统一为轻量的引用标签、输入框与截图预览；按压反馈短而轻，键盘操作即时响应，支持减少动态效果偏好。小窗口中发送按钮避开朗读悬浮按钮。

图像接入依据：[DeepSeek 图像理解](https://api-docs.deepseek.com/guides/vision/)、[Chat Completions 图片参数](https://api-docs.deepseek.com/api/create-chat-completion/)。测试使用本地模拟响应，不读取你的真实密钥、不产生在线 API 费用；实际模型的图像识别和引用遵循情况需配置可用账号后试用。

## 0.12.2：统一为背景色标注

保存的标注只显示淡黄、雾蓝、浅绿或淡紫色背景，去掉原来叠加的下划线；按钮、颜色选择和提示统一使用「标注」。已有摘录和笔记继续保留，原有书中链接的下划线不受影响。

修正从顶部「AI 讨论」进入后仍残留正文临时选中底色的问题：所有讨论入口都会清除当前选区和选中文字工具条。问 AI 本身不新增永久标注，只有主动点击「标注」、加入摘录或保存笔记才保存。

## 0.12.1：AI 讨论与摘录分开

选中文字后点击「问 AI」只创建独立会话，不自动标注，也不加入摘录列表。讨论仍保存在本机并随书架备份，重启后从阅读页「AI 讨论」打开，在会话选择框中切换。

想保留原文时，再点击讨论面板「加入摘录」，或在正文主动标注、保存笔记；会沿用原会话，不复制或丢失讨论。「整理成笔记」打开编辑窗口后，只有确认保存才加入摘录，取消不会保存。单纯选中文字或选择颜色也不新增摘录。

旧版已经保存的摘录继续保留：旧数据没有记录是主动保存还是由问 AI 自动创建，升级时不猜测、不批量删除。旧版程序不认识新的会话标识，请使用 0.12.1 或后续版本查看这些会话。

## 0.12 新功能：独立会话记忆与讨论整理

- **每段一个会话**：每段原文分别保存完整讨论，同一本书内用「切换本书会话」切换。再次选中同一位置的相同原文，会回到已有会话，不新建重复记录或改动已有标注颜色。其他位置、章节或书籍里的文字各自独立，不混合上下文。记录随书架保存和备份，重启后可以继续。
- **模型记住当前会话**：每次发送当前摘录的全部已保存讨论，最多 20 轮，取代 0.11 的最近 6 轮窗口；不发送其他会话或整本书。历史越长，后续输入用量越高。达到上限后可以整理笔记或清空讨论重新开始，不提供跨会话、跨书籍的自动记忆。尚未发送的问题草稿只在本次运行中按会话保留，退出后不恢复。
- **复制与重新生成**：每条已保存回答可复制为纯文本；最后一条回答可重新生成，沿用原问题和更早的上下文，使用当前选定模型，产生新的 API 用量。完整新回答成功保存后才替换旧回答；失败或停止时旧回答不变。重新生成不增加轮数，写入失败时仍可只重试本地保存。
- **删除与清空**：删除较早的一轮时，同时删除其后依赖该上下文的讨论，确认窗口明确显示删除轮数；也可以清空当前会话。原文、标注、自己的笔记和其他会话保留。删除没有撤销，确认前可以取消；已导出的备份仍可能包含旧记录。

## 0.11 功能：DeepSeek AI 伴读

1. 从书架打开「AI 伴读设置」，粘贴自己的 DeepSeek API Key。
2. 点击「检测连接并获取模型」，从检测到的列表选择模型；也可手动填写模型 ID。默认 `deepseek-flash`，具体可用模型以服务商实际返回为准。
3. 可点击「测试一句回答」，确认能生成文字；测试会产生少量 API 费用。保存设置后，输入框清空，之后留空继续使用已保存的密钥。
4. 正文选中文字，点击「问 AI」，为这段原文打开淡蓝色伴读面板；0.12.1 起不自动摘录或标注。可从阅读页「AI 讨论」继续会话，已有摘录也可点「问 AI／继续讨论」。打开面板不会自动调用模型。
5. 输入问题并发送，回答流式显示，可停止。点击「整理成笔记」会再调用一次 AI 生成草稿，先保存这轮讨论，再打开笔记编辑窗口；确认保存后才改动自己的笔记。已有笔记会保留在草稿开头，合计最多 2000 字符，过长的生成内容截取剩余可用长度。

仅发送书名、作者、摘录所在章节编号、选中原文和当前会话全部已保存讨论（最多 20 轮），不读取整本书，也不自动附加后文。提示模型区分原文明示和可能的解读、不要主动剧透；模型可能已经知道作品情节，因此不能保证绝无剧透。默认关闭深度思考，单次最多生成 1800 tokens，界面展示服务商返回的实际 token 用量，不估算货币账单。对话每条摘录最多 20 轮，回答最多 12000 字符，问题最多 1500 字符。达到 20 轮后，整理按钮改为「将回答加入笔记」，直接把最后一条回答填入可编辑草稿，不再调用模型。

完整讨论随会话原文保存在 `library.json`，重启、笔记改色、编辑和删除撤销后保留，也包含在书架备份中。重复合并相同摘录和笔记时，有本地讨论则保留本地版本，没有时补回备份讨论；不自动合并分叉对话。删除摘录时也删除其讨论并取消正在生成的回答；删除后的撤销恢复已保存的讨论。

密钥由 Electron `safeStorage` 使用 Windows 系统保护加密，单独存于用户数据目录 `ai-settings.json`，不返回给阅读页面、不记录日志、不加入书架备份。换电脑或 Windows 账户后需重新填写。检测、测试和问答只访问固定的 `https://api.deepseek.com`，拒绝重定向，不使用网页版登录凭证，不共享或扫描其他厂商密钥。检测模型不发送书籍正文；启用前需要自己的可用 API 账户，费用记在 DeepSeek 账户上，不能使用 ChatGPT Plus 的额度。

断网、密钥错误、余额不足和服务繁忙会显示可重试提示；停止或关闭面板会取消请求，不保存未完成的回答，服务商可能已经计入部分用量。完整回答生成后若本地写入失败，使用「重试保存回答」只重试本地写入，不再次调用模型；正常退出前会再次尝试保存，失败则保留窗口和内存中的回答。AI 设置损坏不会阻止阅读原有书籍，可在设置中重新配置。

接入依据：[DeepSeek 官方入门](https://api-docs.deepseek.com/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[模型列表](https://api-docs.deepseek.com/api/list-models/)。第一版只接 DeepSeek，不提供任意地址、其他厂商或 ChatGPT 登录授权。

验证使用官方响应格式的本地模拟服务，覆盖 Windows 密钥加密、模型检测、逐段响应、取消、持久化、重启、笔记草稿和写入失败恢复；截图中的 AI 回答为演示数据。未配置真实密钥时不进行付费在线测试，首次实际使用需在本机配置后点击测试。

## 0.10 功能

- **四色标注**：选中文字后，在气泡中选择淡黄、雾蓝、浅绿、淡紫，再标注或写笔记。「摘录」可按颜色筛选，在编辑窗口改色；正文采用浅色背景，不叠加下划线，回到原文时短暂加深对应颜色。旧摘录自动使用淡黄，颜色随笔记保存、备份和恢复；重复恢复同一原文和笔记时保留当前颜色。
- **三个朗读音色**：Serena（默认，温柔女声）、Vivian（明亮女声）、Uncle_Fu（醇厚男声）。在耳机面板切换，或从「本地语音包」选择试听；选择会全局保存。三个音色共用现有本地 Base 模型，已安装 0.6 及之后语音包的电脑不需要重新下载模型；各音色使用固定参考声音，保持平稳叙述，自动文学情绪分析仍暂缓。
- **切换行为**：切换时取消旧音色的播放和预取，从当前片段开头重新准备声音，保留语速、暂停状态、手动浏览状态及定时设置。跨章正在加载时切换会停止续读，可点「继续上次听读」恢复；不同音色的缓存互不混用。模型共用一个进程，首次切换仍有短暂准备时间。

开发验证：`node scripts/smoke-voices.js` 使用 `READINGTEXT_VOICE_HOME` 指定的已安装语音包，输出三个音色朗读相同两段原创文字的 WAV、单模型进程验证、耗时及取消重试报告。参考声音的来源、校验和及复现方法见 `assets/voice/README.md`。

## 0.9 功能

- **四种阅读背景**：暖白、雾蓝、浅灰、米杏，在「Aa 排版」选择；浓淡可从 0–100% 调整，0% 为白色纸面。正文和阅读区域一起改变，玻璃面板保留；设置全局保存，切换字体或背景时保留阅读段落。
- **标注与笔记**：在正文选中文字，出现「标注／写笔记」气泡，支持同一章内跨段选择。每条摘录最多 4000 字符，笔记最多 2000 字符，每本书最多 1000 条；「摘录」面板可查看、编辑、回到原文和删除，删除后有 8 秒撤销。用原文位置保存，换字体、重启后仍保留；不在正文插入标签，不改变原文、搜索及朗读。
- **备份与恢复**：书架顶部打开「备份与恢复」，导出 `.readingtext` 文件，包含 EPUB 副本、分类、书签、摘录／笔记、阅读／听读进度和排版／朗读设置。恢复时先检查文件并展示数量，再确认合并；已有书籍保留当前进度和分类，补充缺失书签和摘录，同一原文但不同内容的笔记分别保留。空书架同时恢复设置；重复恢复不会反复添加同样内容。

备份在本机生成，语音模型不放入备份，换机后可重新下载。当前单个备份最多 250 MB、书籍累计最多 500 MB、最多 500 本书、元数据最多 16 MB；封面从 EPUB 重建。文件校验失败不会开始恢复，恢复写入失败时原有书架元数据保持不变；中断后可能留下尚未引用的书籍副本，重试会复用。不要在程序运行时手动修改或移动数据文件。

## 0.8 功能

- **自动跨章朗读**：默认本章读完后接着下一章，跳过没有可朗读文字的章节，读到全书末尾停止。面板可关闭自动续读，重启保留选择；手动切章、返回书架和点击停止仍会结束当前朗读。下一章读取失败可以重试，切换过程中也可暂停或停止。
- **定时停止**：支持 15、30、60 分钟和「读完本章」。分钟定时从选择时开始，准备声音、暂停、收起面板、最小化期间继续计时，到点停止播放和后台准备；「读完本章」优先于自动续读。可改选时间或取消；手动停止、切章、返回书架、退出后会取消定时，下次启动不会沿用。
- **朗读文本整理**：仅整理送去合成的副本，不改书籍显示、搜索和书签。合并中文断行，保留英文词间空格；跳过明确标注的页码及 EPUB 页码标记、连续重复的标题和纯分隔线。ISO 日期、百分比、常见带单位数字、章节序号转成中文读法，例如 `2026-10-15`、`12.5%`、`35元`。裸数字、电话号码、版本号和不合法日期保留原样，不猜测所有数字的含义。

继续使用现有 Serena 语音包，不需要额外下载模型。文本整理可以减少格式引起的停顿和误读；人名、多音字、缩写及复杂公式仍由原模型处理。声音本身的语气与发音仍需实际试听。

## 0.7 功能

- **收起式朗读**：右下角耳机图标展开淡蓝玻璃面板，关闭面板后继续播放与高亮。进入全屏自动收起，退出时恢复此前的展开状态，耳机上的小圆点显示播放／暂停状态。
- **连续语速**：滑块范围 0.60–2.00 倍，每格 0.05；默认 0.90 倍，可一键恢复 1.00 倍。保持音调，不重新生成，重启保留语速。
- **边生成边播放**：本地声音按片段传给播放器，无需等待整段完成。默认打开书籍时提前准备已安装的模型；朗读面板可关闭自动准备。模型仍在内存中保持到退出，以便继续阅读。
- **连续预取**：正常速度预取下一片段，1.50 倍及以上预取两个。跳段与停止会取消旧声音，缓冲未跟上时显示提示。
- **语气实验**：保留固定 Serena 音色，只在开发对照中测试轻微重音和语气变化；正式界面继续使用平稳叙述，避免破坏连续性。`node scripts/compare-serena-stream.js` 生成三段原创文字的平稳／自然语气 MP3 与首包耗时报告，试听后再决定是否开放。

首次启动仍包含本地模型加载和 GPU 热身，不能保证立即出声；已准备后的等待通常更短，实际取决于显卡、文本及缓存。自动准备会增加显存占用，不会下载未安装的模型，也不会上传正文。

## 0.6 功能

- **声音衔接调整**：各段使用固定的 Serena 参考声音，降低随机变化；较长段落尽量保持完整，减少中途重新起调。统一响度并柔化接缝，短段间补 0.18 秒停顿，保留少量自然余音，不叠加过长留白。
- **上一段／下一段**：按完整段落跳转，长段内的多个声音片段视为同一段。暂停时跳段会从目标段开始播放。
- **继续上次听读**：每本书独立记住实际听到的段落与片段，重启后点击此按钮恢复；即使手动看了其他章节，也能回到上次听读位置。恢复从片段开头开始，不恢复到精确秒数。
- **旧语音包升级**：0.5 的语音包会显示更新入口，额外下载约 4.23 GiB 模型，复用现有运行环境。旧模型保留，方便继续运行 0.5。声音是否更自然，建议试听同一组三段文字的新旧对照。

0.6 不包含自动跨章朗读、语速滑块和多段共享生成。独立听读记录只在声音实际开始播放时更新，后台预取不改变进度。

## 0.5 功能

- **Serena 本地朗读**：在书架或阅读器打开「语音包」，下载后可试听、移除。下载需要联网，正常朗读不上传正文；使用独立便携环境，不修改系统 Python。首次安装建议预留 15 GB 空间，已安装约占 9.3 GiB。
- **播放控制**：朗读面板从最上方可见段落开始，支持暂停、继续、停止和错误重试。朗读模式下点击正文段落可跳读；选中文字或点击章节链接保留原有行为。
- **三档语速**：舒缓、标准、稍快，默认舒缓。调整播放速度时保持音调，不重新生成；0.7 已改为连续滑块。
- **淡蓝玻璃气泡**：正在播放的段落以浅蓝圆角气泡高亮，暂停保留、停止清除；长段落按句拆分生成，仍高亮同一整段。
- **自动跟随**：段落超出可见范围时跟随；手动滚轮、滚动键或拖动滚动条时暂停页面跟随，声音继续。「回到朗读处」恢复跟随。
- **准备与预取**：明确显示准备状态，只提前准备下一个文本片段。停止、跳读或切章会取消旧任务；读完本章停止，返回书架也停止。

此体验版使用 NVIDIA GPU 加速，已在本机 RTX 5090 通过真实离线声音验证。首次朗读约需半分钟准备，之后复用模型；未覆盖 AMD、核显或纯 CPU。模型加载期间仍可停止；退出程序或移除语音包会释放模型。来源与授权见 [语音说明](assets/voice/README.md)。

## 0.4 功能

- **右键拖动整理**：在书架按住书籍封面的右键，拖到左侧目标分类后松开。拖到「全部书籍」或「未分类」会解除分类；拖到空白处或按 Esc 取消。每次移动后提供 8 秒的「撤销」入口，原有「⋯」菜单也可使用。
- **离线阅读字体**：系统默认、思源宋体、思源黑体和霞鹜文楷屏幕阅读版。每本书单独记住字体，新书首次阅读继承最近使用的字体；切换字体保留当前阅读段落。
- **独立段距**：段落之间的空隙可在 0–2.4 倍字号之间调整，与行距分开设置；段距等其余排版设置对所有书生效并在重启后保留。

目前拖动一次处理一本书，仅支持右键；分类仍为一级文件夹。随程序提供未经修改的开源字体，来源、固定版本和授权见 [字体说明](assets/fonts/README.md)，正常使用无需下载字体。

## 0.3 功能

- **柔雾玻璃界面**：低饱和灰绿、米杏背景，静态透明气泡和磨砂面板。阅读正文保留清晰的白色纸面；不支持磨砂效果时使用实色背景。
- **继续阅读封面**：显示当前书籍内嵌的真实封面，完整展示；没有封面或图片无法显示时，用书名和作者生成默认封面。
- **一级分类文件夹**：左侧「我的分类」旁点击加号新建，支持重命名和删除；每本书归属一个分类，未分组的书放在「未分类」。
- **整理书籍**：点击书卡右下角「⋯」，选择目标分类；有分类时导入 EPUB 会先让你选择放入的位置。
- **保留阅读数据**：删除分类会把其中的书移回「未分类」，不会删除电子书、进度或书签。分类名称最长 30 个字符，最多 100 个分类；暂不支持子文件夹和多标签。

## 0.2 功能

- **书签**：在「书签」面板保存当前位置，记录章节和正文摘要，支持跳转和删除。书签按书保存，重启后仍保留；同一段落不会重复添加。
- **书内搜索**：输入关键词后按 Enter，搜索所有正文阅读章节，展示章节名和上下文。点击结果会跳到匹配文字并以黄色显示。搜索不区分大小写，每次最多显示前 200 处匹配。
- **返回原位置**：从目录、书签、搜索结果或正文链接跳转后，点击「返回原位置」可以逐次回到跳转前的阅读位置。最近 50 次跳转在当前阅读会话内有效，返回书架或重新打开书籍后清空。
- **全屏阅读**：工具栏按钮或 F11 进入和退出，Esc 退出；返回书架也会退出全屏。保留工具栏，方便继续访问目录、书签和退出按钮。

搜索过程中可重新输入并提交新关键词；离开当前书籍会取消尚未完成的搜索。

## 第一版范围

- EPUB 2 / 3 的普通文字书籍，支持 EPUB 3 导航目录和 EPUB 2 NCX 目录。
- 本地导入、文件内容去重、书架、原生封面或默认封面、删除确认。
- 按章节上下滚动阅读，基础图片、标题、段落、强调、列表和表格。
- 章节及章节内锚点跳转；损坏目录会回退到书籍的章节顺序。
- 明亮主题、系统默认字体，字号、行距、阅读宽度自动保存。
- 每本书单独记住章节、段落及段落内相对位置；书架进度按章节数估算。
- 不依赖账号或网络，书中脚本、远程资源与外部跳转被禁用。

后续再考虑更多主题及多设备同步。

### 已知边界

第一版针对普通文字排版，不支持 DRM 加密书籍、固定版式、漫画、音视频、竖排、嵌入式字体和原书复杂 CSS。为了统一排版，正文使用阅读器自身的样式，不保留原书的 CSS。SVG 文件作为图片可显示，正文内嵌 SVG / MathML 暂不支持。

单本 EPUB 最大 100 MB，解压后总大小最大 600 MB，单个章节最大 4 MB。不支持跳到阅读顺序以外的附录文件。关闭阅读器时会等待进度保存；如果磁盘写入失败，会提示错误并保留窗口以便重试。强制结束进程或断电可能丢失最后一小段尚未保存的进度。

## 数据位置

默认保存于 `%APPDATA%\ReadingText`：

```text
ReadingText/
  library.json          书架分类、排版／朗读设置、阅读／听读进度、书签和摘录／笔记
  books/<内容哈希>.epub  导入的书籍副本
  voices/serena/         可选语音模型、独立运行环境及临时音频
```

移动或删除原始 EPUB 不影响已经导入的书籍。移除书籍会删除书架副本及其阅读位置，不删除原始文件。备份时请先关闭阅读器，再复制整个 `ReadingText` 文件夹。

如果 `library.json` 损坏，程序会停止启动并显示提示，保留原有文件，不自动重置书架。

## 开发与验证

需要 Windows x64 和 Node.js 22.12 或更高版本。

```powershell
npm install
npx --no-install install-electron --no
npm start
```

首次安装 Electron 和构建所需组件需要联网，正常阅读不需要联网。

```powershell
npm test          # EPUB 解析、持久化、异常处理与输入校验
npm run test:e2e  # 真实 Electron 窗口中的导入、阅读、重启恢复、删除与内容隔离
npm run check    # 所有 JavaScript 文件的语法检查
npm run build    # Windows x64 免安装程序
node scripts/smoke-portable.js # 对构建后的免安装启动器进行实际启动检查
```

真实语音验证需先安装语音包，并设置 `READINGTEXT_VOICE_HOME` 指向包含 `serena` 的目录，再运行 `node scripts/smoke-serena.js` 与 `node scripts/smoke-serena-desktop.js`。前者验证离线生成、取消及重试，并在 dist 生成原创试听音频和耗时报告；后者验证真实 Electron 播放、高亮、跳段、恢复、自动跨章、数字朗读、本章定时停止及退出，并生成数字朗读样本，加上 `--install` 可验证真实安装。`READINGTEXT_EXECUTABLE` 可指定打包后的可执行文件。

音频数值测试使用语音包内的 Python：`python -m unittest discover -s tests -p voice_audio_test.py`，覆盖静音整理、响度、字音边缘、流式接缝、MP3 编码、限幅和异常数据。`node scripts/compare-serena.js <旧版worker.py>` 在保留两代模型的测试语音包中生成同文三段新旧对照；测试用的旧 worker 可从 Git 提交 `7d40394` 读取。

桌面测试使用仓库内 `.test-data` 中的独立书架，不使用个人书架。朗读交互测试使用原创的受控静音 MP3 测试样本（tests/speech-fixture.mp3），真实模型另用上述两项检查验证。`test-results` 保存测试截图与失败追踪文件。示例 EPUB 由 `scripts/make-demo.js` 生成，正文为本项目原创。

技术组成：Electron、原生 HTML/CSS/JavaScript、JSZip、fast-xml-parser 和 DOMPurify。使用隔离的预加载接口、沙盒阅读框架和限制资源访问的本地协议；不加载远程网页。

## 发布说明

仓库中的 `Windows release` 工作流在 `main` 的版本号或发布流程更新时运行，也可从 Actions 手动运行。它会安装依赖与 Electron、运行单元测试和语法检查、构建并检查免安装程序，最后按 `package.json` 版本创建 GitHub Release，附上 EXE 和 SHA-256 摘要。更新前请同时调整 `package.json`、`package-lock.json` 与界面版本；已有 Release 不会被覆盖。构建只使用仓库内素材，不包含个人书架、API 密钥或下载的语音模型。

当前构建未进行 Windows 代码签名。分享程序前请确认来源可信；Windows 可能显示未知发布者提示。此版本供 MVP 体验使用。
