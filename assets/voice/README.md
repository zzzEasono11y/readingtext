# 本地朗读音色

本项目不内置模型权重，不调用云端朗读接口。语音包由用户在界面下载到本机后使用，模型下载来源固定为 Qwen 官方仓库。书籍正文通过本机标准输入管道传给独立工作进程，不启动 HTTP 服务，不上传正文。

0.10 增加 Vivian（明亮女声）及 Uncle_Fu（醇厚男声），默认仍为 Serena。三个音色共用既有 Base 模型及一个工作进程，通过不同的固定参考声音合成，不另下载 CustomVoice 权重。参考音频由官方 CustomVoice 模型的原生预设生成，均为合成声音，不是真人录音。运行时逐个校验清单与文件的 SHA-256；缓存键包含音色，取消旧流后才准备新音色，避免混用结果。新音色首次提取参考特征仍需短暂等待。

新音色参考文件由 `scripts/make-voice-references.py` 使用已安装的旧 CustomVoice 模型复现：固定官方 revision `0c0e3051f131929182e2c023b9537f8b1c68adfe`、随机种子 1627、temperature 0.6、top_k 30；脚本接收 `serena` 语音包根目录，不会下载模型。硬件或底层库改变时生成字节可能不同，发布的文件以清单固定值为准。

两个新音色的原创参考文本均为：“清晨，窗边的光落在翻开的书页上。你不必急着读完，只要在这一刻，给自己留一点安静的时间。”

- `Vivian-reference.wav`：11.16 秒，SHA-256 `9bc30e1b246b200e108c681c0b67c00650bfe4c99941c5b48ab20c9efecb3218`。
- `Uncle_Fu-reference.wav`：11.08 秒，SHA-256 `61399c7cae8e1b049dea06b871bbcff0ad960ea038998d7d44d569ec58685153`。

全部参考文件为 24 kHz 单声道 PCM16。`voices.json` 保存音色名称、描述、参考文本和文件摘要，程序随包附带这些小文件。音色偏好与备份一起保存；旧设置缺省为 Serena，语气仍使用平稳叙述，自动文学情绪分析未开放。

- 0.6–0.8 模型：[Qwen3-TTS-12Hz-1.7B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base)，固定 revision `fd4b254389122332181a7c3db7f27e918eec64e3`。各段统一参考同一段 Serena 音频，固定随机种子并降低采样温度，以减少音色和语气变化；模型页面声明 Apache-2.0。这不是多段共享一次生成，上下文及语气连续性仍需试听评估。
- 参考声音：`Serena-reference.wav`，由 0.5 版本使用 [CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice) 固定提交 `0c0e3051f131929182e2c023b9537f8b1c68adfe` 的原生 Serena 生成，不是真人录音。参考文本为“你好，我是 Serena。留一点时间，给阅读。愿这些文字，陪你度过一段安静的时光。” SHA-256：`915413eddfe08e690b1e69d656b18a7d5cb22f5451c1201ad9163b2c570412fe`。
- 推理：[Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)，`qwen-tts==0.1.1`，Apache-2.0，完整授权见 `Qwen3TTS-LICENSE.txt`。
- 加速：[Faster Qwen3-TTS](https://github.com/andimarafioti/faster-qwen3-tts)，`faster-qwen3-tts==0.3.0`，MIT，完整授权见 `FasterQwen3TTS-LICENSE.txt`。
- 独立运行环境：Python 3.12.10 Windows x64 embeddable，PyTorch / torchaudio 2.10.0 CUDA 12.8。运行环境、组件及其许可证保留在安装后的 `serena/python` 中，依赖固定于 `src/voice-constraints.txt`。下载的 Python 与 pip 压缩包在解压前验证 SHA-256；模型由 Hugging Face 固定提交下载，不运行远程自定义模型代码。

每个文本片段最大 360 个 UTF-16 代码单元，在句子边界尽量分段，减少长段内部重新起调。0.7 将生成中的声音通过已有 soundfile / libsndfile 编码为连续 MP3（约 160 kbps），经本地 IPC 传给 MediaSource 播放器，不启动网络服务、不新增依赖；浏览器保持音调地调整 0.60–2.00 倍速度，每步 0.05，默认 0.90 倍，共用生成结果。完整 WAV 接口仅用于离线验证。长段落拆分后仍只高亮同一段落。

流式播放整理开头静音，保留约 40ms 前缘、滚动保留 250ms 尾部并尽量留 60ms 余音；已经发出的尾部静音无法召回。每个片段只在开始时确定一次增益（约 ±4dB），后续保持一致并限幅至 0.94，首尾做 8ms 淡入淡出，内部流块不淡出、不删样本。播放时不同段之间补 180ms，同段内补 30ms；这部分停顿与语速无关，可以暂停和取消，不交叠人声。

听读位置按每本书独立持久化，记录实际播放的章节、正文块及片段编号，与手动阅读位置分开。只有实际播放才推进记录，预取不推进。恢复从片段开头开始；上一段／下一段按正文块跳转，跳过长段内部的剩余片段。

默认预取下一个片段，1.50 倍及以上预取两个；最多三个未消费的流，单流最多 5 MiB，内存最多缓存八个生成结果。停止或跳转会取消旧任务、丢弃旧响应并清理音频对象；工作进程会在下一个生成片段边界响应取消。未播放的音频不会触发高亮。临时 WAV 位于 `serena/audio`，读取后删除，下次进程启动清理残留。模型保持加载以便继续阅读，退出应用或移除语音包时释放 GPU。

此版本只验证了 Windows x64 / NVIDIA RTX 5090、CUDA 可用的本机环境，尚未覆盖 AMD、核显或仅 CPU。初次启动包含 Python 导入和 GPU 图准备，需要等待；模型热身后速度显著提高。默认在打开书籍时预热已安装的模型，可在面板关闭后续自动预热；不会自动下载语音包。暂停、手动滚动与语速调整不重新生成声音。

0.6 模型独立保存在 `serena/model-continuous`，就绪标记为 `continuous-ready.json`。升级下载约 4.23 GiB 模型；旧 `model` / `ready.json` 原样保留供 0.5 使用，现有运行环境复用。首次全新安装约 9.3 GiB，保留两个版本时约 13.6 GiB；界面「移除语音包」会移除整个 Serena 目录及两个模型。

0.7 的自然语气只作开发试听：同一组原创三段文字、固定参考音色与随机种子，比较无指令的平稳版和带轻微语气指令的试验版。Base 模型对语气指令的遵循度与段间一致性不能仅靠数值证明；未通过主观试听前不加入正式界面。脚本 `scripts/compare-serena-stream.js` 同时测量冷加载、热启动首包与整段完成时间，并验证取消重试。

0.8 在朗读前对 DOM 副本做保守整理：跳过明确页码、语义页码标记、连续重复标题和纯分隔线；合并中文换行，同时保留英文词间空格。常见 ISO 日期、百分比、带单位的四位以内数字和章节序号转为中文读法；裸数字不删除，电话号码、版本号、无效日期不强行转换。只影响送往模型的文字，原书显示、搜索和进度块编号不变；不覆盖人名、多音字、复杂公式及所有外语缩写。

默认自动续读下一章，跳过无可朗读文本的章节。手动切章仍停止，只有实际播放才更新听读位置。定时可选 15 / 30 / 60 分钟和本章结束，分钟按实际时钟计时（暂停和准备时也计时）；禁用后台节流以便最小化后仍可定时。停止、切章、返回书架或退出会清除定时；不在重启后恢复倒计时。到点会停止播放并取消未完成的合成任务，仍按既有策略保持模型加载。
